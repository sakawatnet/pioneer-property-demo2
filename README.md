# Pioneer Property Management Website

Static HTML website prepared for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `value-solutions.html` — Value Solutions
- `leadership.html` — Leadership
- `portfolio.html` — Portfolio & Testimonials
- `contact.html` — Contact Us

## Publish on GitHub Pages
1. Extract this ZIP.
2. Create or open a GitHub repository.
3. Upload the contents of this folder (make sure `index.html` is in the repository root).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.

## Notes
- This is a static site and uses Tailwind CSS CDN and Google Fonts, so those resources require an internet connection.
- Contact/audit forms in the supplied design currently show a client-side success message only; they do not send submissions to an email or database. Connect a form service or backend before using them for real leads.
- Review business details, phone numbers, email addresses, claims, and testimonials before publishing.
